# Inventory Sales & Purchase Dashboard — Power BI

## Project Overview
This portfolio project demonstrates how Microsoft Power BI can be used to analyze sales, purchasing, inventory levels, and supplier performance through interactive dashboards.

## Business Objectives
- Monitor total sales, profit, and purchase costs.
- Track inventory value, closing stock, and damaged units.
- Analyze supplier performance and purchase fulfillment.
- Monitor order status, pending units, and average lead time.
- Present key performance indicators (KPIs) to support business decisions.

## Tools & Skills
- Microsoft Power BI
- Power Query for data preparation
- Data modeling
- DAX measures and KPI calculations
- Data visualization and dashboard design

## Dashboard Pages
- **Executive Dashboard:** High-level sales, profit, purchasing, and inventory KPIs.
- **Sales & Purchase Analysis:** Sales and purchasing performance.
- **Inventory Analysis:** Stock levels and inventory-related indicators.

## Deliverable
The Power BI report file (`.pbix`) is included in this repository for portfolio review.

## About This Project
This is a portfolio project created to demonstrate Power BI and business data analysis skills. The results and metrics should be interpreted according to the dataset and assumptions used in the report.
